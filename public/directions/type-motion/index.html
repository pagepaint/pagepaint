Make the next fix obvious.

  1. 01

    Mark the page

    Open Feedback and choose Draw & capture. Use a pen, highlighter, rectangle, or circle to show exactly what needs attention.

  2. 02

    Add the context

    Attach the capture or record a short clip. Add your comment. Pagepaint keeps the full URL, query parameters, and viewport with it.

  3. 03

    Keep it with the code

    Choose your repo folder when saving, or keep feedback in browser storage. Download a ZIP whenever you need to hand it over.

Give your agent the evidence.

Repo saving writes the capture, recording, and JSON into .annotations/. Add this line to AGENTS.md or CLAUDE.md:

Check .annotations/ for open items; set status to resolved when done.

Folder access needs desktop Chrome or Edge on HTTPS or localhost. Other browsers can use browser storage and ZIP export. 

.annotations/
  feedback.json
  feedback.webp
  feedback.webm

status: "open" → "resolved"
