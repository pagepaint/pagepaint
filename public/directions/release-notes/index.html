Feedback, right where the problem is.

Pagepaint adds a feedback toolbar to your app. Draw on the page, capture a screenshot or video, and leave a comment.

Built for developers and QA reviewing AI-built apps. The URL and viewport travel with every note.

Your feedback stays on this device. No feedback server or account required.

One script.
Your app.

Add this before </body>. Works with static pages, client apps, and server-rendered HTML.

index.html 
<script src="https://pagepaint.dev/v0.4.0/pagepaint.js" data-pagepaint defer></script>

The versioned URL pins v0.4.0. No build step or local Node server needed.

A useful bug report, in three steps.

Open the toolbar in the app you’re testing. Keep the evidence and the explanation together.

  1. 01

    Point it out.

    Use a pen, highlighter, rectangle, or circle directly on the page. Capture the view, or record a short video.

  2. 02

    Say what happened.

    Add a comment and send. Notes, drafts, and attachments save in this origin’s browser storage (IndexedDB).

  3. 03

    Hand over the context.

    Choose your repo folder to save ordinary files in .annotations/, or download everything as a ZIP.

Files your agent can read.

Repo saving writes the comment, full URL, viewport, shapes, and status into JSON beside the capture or recording. 

.annotations/
  <id>.json
  <id>.webp
  <id>.webm

Add a line to AGENTS.md or CLAUDE.md

Check .annotations/ for open items; set status to resolved when done.

Folder access needs desktop Chrome or Edge on HTTPS or localhost, and your permission. Other browsers can use browser storage and ZIP export.

Browser storage belongs to each origin, including localhost ports. Clearing site data removes it; files you saved to your repo remain.

Prefer an extension? Use Pagepaint without changing the app.

The Chrome / Edge extension uses the same tools, with native tab screenshots. Its local history is separate from the CDN widget.

  1. Download the extension ZIP and extract it.
  2. Open chrome://extensions or edge://extensions and enable Developer mode.
  3. Choose Load unpacked, select the extracted folder, then click the Pagepaint extension icon in your app.
