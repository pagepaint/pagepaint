Pagepaint✳

Connect GitHub.

The CDN and extension use a small Cloudflare Worker for OAuth. Feedback stays in your browser; issue creation and attachment uploads go directly from the trusted Pagepaint window to GitHub.

  1. Register a GitHub OAuth App named Pagepaint. Use https://pagepaint.dev for its homepage and https://pagepaint.dev/github/callback for the callback. Leave wildcard matching off and expiring user tokens on.
  2. Generate a client secret and put GITHUB_CLIENT_ID, GITHUB_CLIENT_SECRET, and a random SESSION_SECRET of at least 32 characters into Worker secrets. Never include them in the script, git repository, or chat.
  3. Deploy with cf deploy --prebuilt --secrets-file /private/path/pagepaint-secrets.json after npm run build:cdn. Sign in from Settings → GitHub.

For a different domain, update AUTH_ORIGIN, the custom domain, OAuth callback, and the widget's githubUrl option together. Authentication cookies are encrypted, HttpOnly, and expire within eight hours. No database is required.

OAuth asks for repo and project scopes to support private repositories and Projects. Users review the target and attachments before posting. A fine-grained GitHub App is a future alternative to these broad OAuth scopes.
